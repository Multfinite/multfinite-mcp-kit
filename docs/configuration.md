# Конфигурация текущих установок

У MetaMCP, GLOBAL и LOCAL отдельные каталоги и конфигурационные файлы; общего `.env` для всех компонентов нет. Начать установку и узнать действующие команды можно в [руководстве по раздельной установке](independent-installation.md). Здесь перечислены только файлы конфигурации, которые используют текущие независимые скрипты.

Не публикуйте секреты из приватных файлов и не передавайте их в аргументах процессов или журналах. Не редактируйте файлы состояния `.mcpkit/state.json`, маркеры установки и runtime-состояние gateway вручную: они связывают конфигурацию с принадлежащими проекту ресурсами.

## MetaMCP

Установщик создаёт состояние и секреты в `<каталог MetaMCP>/.mcpkit/`. Приватный `.env` содержит:

| Переменная | Назначение |
|---|---|
| `POSTGRES_PASSWORD` | Пароль принадлежащей этому MetaMCP базы PostgreSQL. Значение генерируется при создании; изменение строки не меняет пароль уже инициализированной базы. |
| `BETTER_AUTH_SECRET` | Секрет авторизации приложения. Сохраните исходное значение вместе с резервной копией базы. |
| `APP_URL` | Origin приложения: схема, имя/IP и необязательный порт, без пути. Для нелокального адреса требуется HTTPS, кроме явно включённого Linux `--lan-ip` режима с незашифрованным HTTP. Основной публичный origin; `apply` обновляет адрес и соответствующую конфигурацию приложения. |
| `METAMCP_ADMIN_EMAILS` | Разделённый запятыми список email администраторов. В обычной установке пустое значение не задаёт allowlist: каждый вошедший пользователь считается администратором. Закройте регистрацию и настройте администраторов до публикации. Linux `--setup` создаёт первого администратора и закрывает UI/SSO-регистрацию до публикации. |
| `EXTRA_TRUSTED_ORIGINS` | Необязательные дополнительные origin через запятую, каждый без пути, учётных данных и завершающего `/`. Поддержка задаётся upstream MetaMCP; добавляйте только доверенные адреса. |

Комплект не патчит исходники и не добавляет собственные runtime-политики endpoints, clean tool names или multi-origin authentication. Эти возможности определяются закреплённой upstream-версией MetaMCP.

Файлы имеют приватные права доступа. Для изменения origin, allowlist администраторов, дополнительных доверенных origin или политики endpoint отредактируйте только соответствующие строки и примените настройки:

```sh
bash linux/run-metamcp.sh apply "$HOME/mcp-kit/metamcp/global"
```

```powershell
.\windows\run-metamcp.ps1 apply "$env:USERPROFILE\mcp-kit\metamcp\global"
```

Команда проверяет текущие контейнеры, тома и секреты. При необходимости пересоздаёт только app-контейнер; PostgreSQL и его том не удаляются. Записанные вручную файлы в слое app-контейнера могут быть потеряны — сделайте резервную копию до применения. Не изменяйте `POSTGRES_PASSWORD` или `BETTER_AUTH_SECRET` как обычные параметры настройки.

## GLOBAL

Приватный `<каталог GLOBAL>/.mcpkit/.env` принадлежит только одному GLOBAL. Основные переменные, создаваемые установщиком:

| Переменная | Назначение |
|---|---|
| `MCPKIT_GATEWAY_KEY` | Ключ доступа к серверам GLOBAL через `X-API-Key`. Один ключ открывает доступ ко всем серверам этого шлюза. |
| `MCPKIT_CONTROL_KEY` | Отдельный ключ управления gateway; не подменяет API-ключ серверов. |
| `NEO4J_PASSWORD` | Пароль принадлежащего этому GLOBAL экземпляра Neo4j. Не меняйте его в файле без отдельного изменения пароля существующей базы. |
| `LLM_API_KEY` | Общий ключ API для Graphiti и Cognee. Без него эти серверы ждут настройки. |
| `LLM_API_ENDPOINT` | Общий адрес API; по умолчанию `https://api.openai.com/v1`. |
| `LLM_API_MODEL` | Общая модель LLM; по умолчанию `gpt-4o-mini`. |
| `LLM_API_PROVIDER` | Провайдер Cognee для LLM и эмбеддингов; по умолчанию `openai`. |
| `EMBEDDING_MODEL` | Общая модель эмбеддингов Graphiti и Cognee; по умолчанию `text-embedding-3-small`. |
| `EMBEDDING_DIMENSIONS` | Размерность эмбеддингов; по умолчанию `1536`. Она должна соответствовать выбранной модели и уже записанным векторам. |
| `CONTEXT7_API_KEY` | Необязательный ключ Context7. |

Для установки или изменения значения LLM/Context7 обновите соответствующие строки и примените конфигурацию только к выбранному GLOBAL:

```sh
bash linux/run-global-servers.sh apply "$HOME/mcp-kit/global"
```

```powershell
.\windows\run-global-servers.ps1 apply "$env:USERPROFILE\mcp-kit\global"
```

Применение пересоздаёт gateway, Graphiti и Cognee; именованные тома сохраняются, но содержимое записываемого слоя затрагиваемых контейнеров может потеряться. Если меняется `NEO4J_PASSWORD`, сначала нужен согласованный план изменения пароля в уже созданной БД и повторной настройки подключений. Токен GitHub в этой конфигурации не задаётся: укажите его в записи соответствующего сервера MetaMCP. GDrive использует OAuth-файл в приватном томе GLOBAL, а не переменную из этого `.env`.

## LOCAL: Windows и Linux

Каталоги LOCAL имеют файлы `config/local-settings.json` и `config/private/secrets.json`. Linux LOCAL по умолчанию устанавливается в `~/mcp-kit/local`, Windows LOCAL — в `%USERPROFILE%\mcp-kit\local`. При установке в другой каталог передавайте тот же путь командам `run-local-servers` и `connect-local`.

### `local-settings.json`

| Поле | Назначение и ограничения |
|---|---|
| `version` | Формат настроек; создаётся скриптом. Не меняйте вручную. |
| `hostId` | Идентификатор LOCAL-машины для регистрации. Не меняйте на существующей установке без повторной проверки зарегистрированных серверов. |
| `listenHost` | По умолчанию `127.0.0.1`. Нелокальное прослушивание требует TLS или явного `allowInsecureLan: true`; это разрешение не шифрует трафик и не настраивает брандмауэр. |
| `port` | Порт gateway, по умолчанию `13001`; диапазон `1–65535`. Порт должен быть свободен. |
| `tlsCertFile`, `tlsKeyFile` | Пусты по умолчанию. Для TLS укажите оба абсолютных пути к существующим PEM-сертификату и закрытому ключу. |
| `allowInsecureLan` | По умолчанию `false`. Только явный opt-in для HTTP вне loopback; используйте лишь в отдельно защищённой сети/туннеле и ограничьте источники подключений. |
| `projectsDir`, `writingDir` | Каталоги файловой системы и индексации. По умолчанию `<LOCAL>/data/projects` и `<LOCAL>/data/writing`; пути могут указывать за пределы каталога комплекта. |
| `everythingSdkPath` | Абсолютный путь к `Everything64.dll` SDK на Windows; по умолчанию `<LOCAL>/runtime/everything-sdk/Everything64.dll`. Linux использует `locate/plocate` и не предоставляет Windows Everything. |
| `obsidianHost`, `obsidianPort` | Адрес Local REST API Obsidian; по умолчанию `127.0.0.1:27124`. Поддерживается только loopback. |

Редактируйте настройки в JSON, сохраняйте абсолютные пути, затем штатно перезапустите выбранный gateway:

```sh
bash linux/run-local-servers.sh restart "$HOME/mcp-kit/local"
```

```powershell
.\windows\run-local-servers.ps1 restart "$env:USERPROFILE\mcp-kit\local"
```

### `secrets.json`

| Поле | Назначение |
|---|---|
| `gatewayApiKey` | Случайный 64-символьный hex-ключ для `X-API-Key` на `/servers/<server-id>/mcp`. Имеет доступ ко всем серверам этого LOCAL. Не заменяйте его без согласования существующих записей MetaMCP. |
| `obsidianApiKey` | API-ключ плагина Local REST API Obsidian; без него сервер остаётся в ожидании настройки. |
| `dbhubDsn` | DSN DBHub. При пустом значении используется SQLite `<LOCAL>/data/dbhub.sqlite`. Строка DSN может содержать пароли и другие секреты. |

Ключ `X-Mcpkit-Control`, используемый локальными командами `start/status/stop`, отделён от `gatewayApiKey` и хранится в runtime-состоянии работающего шлюза. Не копируйте его в MetaMCP.

На Windows параметры `-NonInteractive`, `-InstallBuildTools`, `-SkipEverything` и `-SkipBrowserDownload` относятся к `windows/install-local-servers.ps1`; `-Port` применяется только при создании настроек. Полные команды и ограничения установки см. в [руководстве](independent-installation.md#3-отдельный-local).

## Сеть WSL и Windows

Локальные адреса, маршруты и порты не создаются конфигурационными файлами MetaMCP/GLOBAL/LOCAL автоматически. Для отдельной схемы подключения [Windows LOCAL к MetaMCP в WSL 2](windows-local-to-wsl-metamcp.md); ограничения и проверку сети см. в [руководстве по Hyper-V и WSL](wsl-hyperv-network.md).
